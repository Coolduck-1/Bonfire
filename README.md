Hi this is the game i made its called bonfire

The commands:
left arrow = left
right arrow = right
space = jump
z = dash (THIS IS IMPORTANT you wont make some jumps without using dash since you need to jump and press dash to not hit your head in the death zones
x = shoot projectiles (2 projectiles kill a fuath)

the objective is to get to the lit campfire in at end of the game, there are checkpoints that activate as you pass trough the will light up to signal their activation.

the fuaths are water spirits that shapeshifted according to the Celts they can be killed by fire and pure metals if im correct you can kill them as i said with 2 projectiles which are little fires

RUNNING THE GAME LOCALLY ON GODOT

To run the game locally you're gonna need the next things:
Have godot installed you can find it on the internet or steam
Have the zip file you get from clicking on code on this github page it should be at the bottom of the pop up menu. 

Next you are gonna unzip the file you downloaded here you are able to see al assets and scenes (no Easter eggs sadly) and from here you open your godot executable and on the right panel you will find the import button browse to the file and click import and edit. 

Finnaly you can click play scene or press F5 if godot asks you to select a main scene you should select menu.tscn since here you can quit, change the volume or press play to start.
